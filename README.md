\# Projeto ONG - Proteção Animal



Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Front-End.



\## Objetivo



Desenvolver uma aplicação web para uma ONG de proteção animal, utilizando HTML, CSS e JavaScript, com foco em organização, responsividade e interatividade.



\## Funcionalidades



\- Navegação no formato SPA

\- Geração dinâmica de projetos

\- Formulário de cadastro

\- Validação de dados com JavaScript

\- Feedback visual de erros e acertos

\- Persistência de dados com localStorage

\- Integração com SweetAlert2

\- Menu responsivo

\- Organização modular do JavaScript



\## Estrutura do projeto



\- `html/` - páginas e estrutura da aplicação

\- `css/` - estilos e responsividade

\- `js/` - funcionalidades JavaScript

\- `imagens/` - recursos visuais



\## Controle de versão



O projeto utiliza Git e GitHub para controle de versão, com organização baseada no GitFlow por meio das branches `main`, `develop` e `feature/formulario`.



\## Tecnologias utilizadas



HTML5, CSS3, JavaScript, localStorage, SweetAlert2, Git e GitHub.



\## Estratégia de versionamento



O projeto utiliza uma organização inspirada no GitFlow:



\- `main`: versão principal e estável do projeto.

\- `develop`: branch de desenvolvimento e integração.

\- `feature/formulario`: desenvolvimento relacionado ao formulário.

\- `feature/documentacao`: melhorias e atualização da documentação.



As mensagens de commit seguem o padrão Conventional Commits, utilizando identificadores como `docs:` para alterações na documentação e `feat:` para novas funcionalidades.


## Execução local

O projeto foi desenvolvido com HTML, CSS e JavaScript e não necessita da instalação de dependências para sua execução.

Para executar a aplicação localmente:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no computador.
3. Acesse a pasta `html`.
4. Abra o arquivo `index.html` em um navegador.
5. Utilize o menu da aplicação para navegar entre as seções Início, Projetos e Cadastro.

Como o projeto utiliza tecnologias executadas diretamente pelo navegador, não é necessário instalar pacotes ou executar comandos de build.
